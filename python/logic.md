সবচেয়ে গুরুত্বপূর্ণ Rule

কোনো problem দেখেই code লেখা শুরু করবে না।

প্রথমে:

1. Problem বুঝো → 2. Example বানাও → 3. হাতে dry run → 4. Steps/pseudocode → 5. Code → 6. Test → 7. Edge case

উদাহরণ:

“একটি number reverse করো।”

সরাসরি code নয়। আগে ভাবো:

1234

শেষ digit = 4
তারপর = 3
তারপর = 2
তারপর = 1

Result = 4321

এরপর বুঝবে % 10 এবং // 10 কীভাবে ব্যবহার করা যায়।
